## 🛒 E-commerce 트래픽 문제 해결을 위한 기술 학습 프로젝트
대규모 트래픽이 발생하는 E-commerce 환경을 가정하고, 발생할 수 있는 여러 문제 상황을 안정적으로 해결하기 위한 기술들을 학습하고 적용한 프로젝트입니다.

## 🎯 학습 목표
안정적인 E-commerce 백엔드 시스템을 구축하기 위해 아래 기술들을 학습하고, 각 기술이 어떤 문제를 해결하는지 이해하는 것을 목표로 합니다.

안정적인 설계: DDD (도메인 주도 설계), TDD (테스트 주도 개발), 설계 문서 작성

성능 최적화: Redis, 데이터베이스 인덱싱, MV, 캐싱 전략

분산 시스템 및 장애 대응: Kafka, 서킷 브레이커 (Circuit Breaker)

## 🏗️ 주요 문제 상황 및 기술 적용
### 1. 복잡한 도메인 관리 및 코드 안정성 확보
   문제 상황: 주문, 결제, 재고 등 E-commerce의 복잡한 비즈니스 로직으로 인해 코드가 쉽게 지저분해지고, 변경 시 버그가 발생할 위험이 높습니다.
 - 적용 기술:
   - **DDD (Domain-Driven Design)**: 주문(Order), 상품(Product), 회원(Member) 등 각 도메인을 명확하게 분리하여 모델링했습니다. 이를 통해 비즈니스 로직의 복잡성을 낮추고 코드의 유지보수성을 높였습니다.
   - **TDD (Test-Driven Development)**: 핵심 기능(예: 재고 차감, 주문 생성)에 대한 테스트 코드를 먼저 작성하여, 기능의 안정성을 확보하고 리팩토링에 대한 불안감을 줄였습니다.
### 2. 순간적인 트래픽 증가로 인한 DB 과부하
문제 상황: 특정 상품의 타임딜이나 이벤트 진행 시, 순간적으로 트래픽이 몰려 데이터베이스에 과부하가 발생하고 웹사이트 전체가 마비될 수 있습니다.
- 적용 기술:
  - **Redis**: 자주 조회되지만 자주 변경되지 않는 데이터(예: 상품 상세 정보, 카테고리 목록)를 Redis에 캐싱하여 데이터베이스 조회 횟수를 획기적으로 줄였습니다. 이를 통해 응답 속도를 개선하고 DB 부하를 감소시켰습니다.

  - **데이터베이스 인덱싱**: 대용량의 주문 테이블이나 상품 테이블에서 특정 데이터를 검색할 때 발생하는 성능 저하를 해결하기 위해, 자주 사용되는 조회 조건(예: product_id, user_id)에 인덱스를 적용하여 쿼리 속도를 개선했습니다.
### 3. 외부 시스템 장애에 따른 서비스 중단 방지
문제 상황: 결제 시스템, 배송 시스템 등 외부 API가 일시적으로 장애가 발생할 경우, 전체 서비스가 중단될 위험이 있습니다.
 - 적용 기술:
   - **서킷 브레이커 (Circuit Breaker)**: 외부 API 호출 시 일정 횟수 이상 실패하면 서킷 브레이커가 작동하여 추가 호출을 차단하고, 빠르게 실패 응답을 반환하도록 했습니다. 이를 통해 장애 전파를 방지하고 시스템의 안정성을 높였습니다.
### 4. 랭킹 시스템 구현
문제 상황: 실시간으로 변동되는 상품 랭킹을 효율적으로 관리하고, 사용자에게 빠르게 제공해야 합니다.

- 적용 기술:
    - **Kafka**: 상품 조회수, 구매수 등의 이벤트를 Kafka 토픽에 발행하고, 이를 소비하는 별도의 서비스에서 랭킹을 계산하여 Redis에 저장했습니다. 이를 통해 실시간 랭킹 업데이트가 가능해졌습니다.
    - **MV (Materialized View)**: 자주 조회되는 랭킹 데이터를 미리 계산하여 저장함으로써, 사용자 요청 시 빠르게 응답할 수 있도록 했습니다.

## About Multi-Module Project
본 프로젝트는 멀티 모듈 프로젝트로 구성되어 있습니다. 각 모듈의 위계 및 역할을 분명히 하고, 아래와 같은 규칙을 적용합니다.

- apps : 각 모듈은 실행가능한 **SpringBootApplication** 을 의미합니다.
- modules : 특정 구현이나 도메인에 의존적이지 않고, reusable 한 configuration 을 원칙으로 합니다.
- supports : logging, monitoring 과 같이 부가적인 기능을 지원하는 add-on 모듈입니다.

```
Root
├── apps ( spring-applications )
│   └── 📦 commerce-api
│   └── 📦 commerce-batch
│   └── 📦 commerce-streamer
│   └── 📦 pg-simulator
├── modules ( reusable-configurations )
│   └── 📦 jpa
│   └── 📦 redis
│   └── 📦 kafka
└── supports ( add-ons )
    ├── 📦 monitoring
    └── 📦 logging
```
